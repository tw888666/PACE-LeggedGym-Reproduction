## 回合与指标的精确定义

沿用当前超时规则 `episode_length > 2000`：最多 2001 个策略步，即 20.01 秒。从首次重置计分，无热身排除；第一次终止即结束该计划回合，自动重置后的数据不得补进它。
接触终止和超时同一步发生时按失败处理；不能仅用现有 timeout 标志推断生存。
终止步的状态、命令和动作必须在自动重置前采集，避免用下一回合初态计算当前回合误差。

每回合线速度 RMSE 为机体平面速度误差平方范数的时间均值开方；偏航 RMSE 为偏航角速度误差平方时间均值开方。全程包括初始暂态；早停回合仍报告终止前 RMSE，但计生存失败并报告持续时间，不能用较短样本掩盖失败。
联合任务成功定义为：达到完整时限且没有失败终止，线速度 RMSE ≤0.30 m/s，偏航 RMSE ≤0.30 rad/s。阈值是预注册项目操作性定义，不是 PACE 论文或作者标准。

| 类别 | 指标及单位 |
|---|---|
| 任务 | 回合线速度/偏航 RMSE、时限生存率、联合成功率、持续时间 |
| 动作 | mean abs(mu)（均值绝对值）、检查点逐关节 std；原始均值绝对值 p95/p99/p99.9/p99.99、超过 2/5/10 的比例；最大值仅辅助 |
| 控制 | 原始 PD 力矩被包络改变的关节子步比例及逐关节值；公式（9）激活比例；真实关节超硬限位比例；原始/安全目标逐关节范围（rad） |
| 能耗 | 电功率 `0.0192*sum(tau^2)`、净机械功率 `sum(tau*qdot)`、净机械功率正部、电功率与净机械正部之和（W）；各项按物理步积分的回合能量（J） |
| 状态完整性 | 归一化统计前后不变、输入/输出有限性、检查点与评估设置记录 |

功率使用 delay FIFO（延迟队列）后实际施加力矩与同一物理步的 qdot（关节速度）。机械正部先逐机器人跨关节求和再取正，不替换为各关节正部相加；另可报告后者但不得混用名称。
功率和明确是当前冻结的诊断指标，不声称包含势能项的完整 PACE 能耗。早停回合不能因累计焦耳较少被判定更节能；必须同时报告平均瓦数、生存与时长。

逐地形、逐难度、逐指令层及其交叉表先完整报告。任务与时间均值类指标先按回合计算再等权平均，主总数为五类型×十难度×三指令层的等权 macro（分层平均）；另报训练地形比例加权的辅助数值时必须标注权重，不能取代主表。
尾部分位数在各分层内合并存活时间的动作标量计算，注明标量数；不能平均各回合分位数当成合并分位数。另提供回合等权超阈值率，揭示寿命加权影响。
逐评估种子列出结果；固定 bootstrap（重采样）seed 910001、2000 次、95% 百分位置信区间。对每个条件与种子内的回合重采样，再计算分层平均；跨阶段比较用配对 case 重采样。
该区间只描述评估随机性；Stage1 仍只有一个训练种子，不能把上万评估回合当成多个独立训练重复。

## 视频与分类决策

GPU 0 或 1 录制确定性视频：每类地形难度行 2/5/8×三个指令层，seed 200000、replicate（重复编号）0，加平地三个指令层，共 48 段。每段到第一次终止或 20.01 秒，25 fps（每秒帧数）；失败片段保留。
固定跟随视角能看清躯干和四腿，标注条件与时间；不根据步态挑选、替换、剪掉失败。渲染缺失记录为缺失，不用另一回合顶替；回放需说明 GPU 改变可能带来的数值轨迹差异，视频不取代定量评估。

操作性“任务达到标准”：主分层平均联合成功率 ≥80%，且分层平均生存率 ≥90%。该分类是项目选择，必须同时展示全部分层；不允许在结果出来后放宽阈值、删去困难地形或挑选检查点。
不设置“动作必须很小”或“饱和必须低于某值”作为通过、推进或重训门槛。以下 A/B 是描述性行为标签，结合连续指标与固定视频说明依据，不伪装成客观硬分类：

- A：任务达到操作性标准，分布与视频未显示明显激进控制特征。
- B：任务达到操作性标准，但仍有激进尾部、饱和或控制行为；如实保留。
- C：任务未达到操作性标准；如实报告当前能耗关闭消融的不足。

A/B/C 均不允许返回 Stage1 调 scale、加动作 L2 或重新挑选熵参数。
Stage1 完成 30k、最终评估和视频报告，且无未解决工程错误后，形成 Stage2 单独执行决议。B 的重点是验证能耗项是否同时压低能耗、动作尾部和饱和；C 若推进 Stage2，必须定位为能耗项能否补足 Task-only 的实验，不能声称已有稳定 Stage1 基线。Stage3 不在此文中自动授权。
