## 平均代价分支

环境保持任务奖励及 FTD（足端触地）课程、机器人参数、控制、容量修复、观测和命令流程。新增分支读取单步有符号修正代价，不加入原 Stage2 能耗奖励。

```math
u_t=\frac{c_t}{\Delta t B_{\mathrm{ref}}},\qquad
\widehat J_C=B_{\mathrm{ref}}\frac{1}{N}\sum_t u_t,\qquad
\overline u=\frac{1}{N}\sum_t u_t.
```

代价评论家使用与任务评论家相同的网络结构，独立参数与优化器，线性输出允许负值。输入复用已更新的评论家归一化统计，不重复计数。初始参数复制任务评论家初始值，随后独立训练；不消耗额外的策略初始化随机数。

预算定义为连续仿真时间上的平均功率，因此代价过程包含自动重置后的下一状态。跌倒和时间上限都不将未来代价设为零；重置本身不虚构额外仿真时间或瞬移能量。差分价值预测相对于平均功率的未来超额代价：

```math
\delta^C_t=u_t-\overline u+V_C(s_{t+1})-V_C(s_t),\qquad
A^C_t=\delta^C_t+0.95 A^C_{t+1},\qquad
R^C_t=V_C(s_t)+A^C_t.
```

采样段结束时使用下一状态价值进行自举估计，并将段外的优势余项置零。代价分支折扣为 1；任务分支仍保留原 PPO（近端策略优化）的折扣 0.99、优势迹系数 0.95、时间上限处理。这里使用有限采样段估计平均功率，评论家和优势均为近似估计，不宣称精确平均代价梯度或论文精确 ECO 实现。

```math
\lambda_{k+1}=\max\left(0,\lambda_k+0.01
\left(\frac{\widehat J_C}{B_{\mathrm{ref}}}-0.9\right)\right),\qquad
A^{\mathrm{combined}}=\widehat A^R-\lambda_{k+1}
\left(A^C-\operatorname{mean}(A^C)\right).
```

任务优势沿用原实现的标准化。代价优势仅去均值，不除以逐批变化的标准差，也不对组合优势二次标准化。乘子初值为 0，无人为上界；当实测超预算时增大，低于预算时减小并投影到非负区间。

组合优势交回原 rsl_rl（强化学习库）1.0.2 的 PPO 更新方法，保留其裁剪、KL（相对熵）自适应学习率、任务价值损失、熵调度、梯度裁剪、训练轮数及小批次逻辑。代价评论家使用独立 Adam（自适应矩估计）优化器，学习率 0.001，5 轮、10 批，沿用价值裁剪幅度和梯度范数；独立的抽样随机数生成器不推进策略随机流。

## 代码与检查点

本入口会产生新的 Stage3 权重。预算比例和新增算法会影响新权重的训练方向；不会修改已有 Stage1/2 权重文件。64 环境的极小预算仅用于强制激活乘子，不能作为行走性能或正式预算实验。
