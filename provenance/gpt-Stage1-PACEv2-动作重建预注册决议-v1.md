## 论文明确语义

`PAPER_EXACT`（论文精确规范）只用于：动作是弧度单位的关节位置偏移；先构造目标，
再按 Eq. (9)（公式 9）处理目标。

```math
\hat q_t=q_0+a_t
```

Eq. (9) 的实际接线及软限位带宽仍是独立阻塞项，本决议不声称它们已经接入。

## 主复现假设

分类：`LEGGEDGYM_DERIVED_REPRODUCTION_ASSUMPTION`（源自 LeggedGym 的复现假设）。
`paper_exact=false`；PACE 运动策略数值确认：`unavailable`（尚不可得）。

```text
关节顺序：LF_HAA LF_HFE LF_KFE RF_HAA RF_HFE RF_KFE LH_HAA LH_HFE LH_KFE RH_HAA RH_HFE RH_KFE
q0 [rad（弧度）] = [0, 0.4, -0.8, 0, 0.4, -0.8, 0, -0.4, 0.8, 0, -0.4, 0.8]
原始高斯策略采样 -> clip（裁剪）[-100,100] -> ×0.5 rad -> a_t
q0 + a_t -> Eq. (9) 目标重塑 -> PD（比例微分）控制器
额外变换：无；不增加 tanh（双曲正切）变换
```

关节缩写：LF/RF/LH/RH 分别为左前/右前/左后/右后；HAA/HFE/KFE 分别为髋外展内收、
髋屈伸、膝屈伸关节。这里采用项目标准关节顺序，而非数据归档的原始顺序。

数值保持当前 [动作配置](../src/pace_stage1/config.py) 的值；裁剪执行于
[环境步进](../src/pace_stage1/env.py)，尺度及默认姿态相加见
[目标语义](../src/pace_stage1/semantics.py)。尺度和裁剪的固定来源为 LeggedGym
`8fa29acc6fd1910c3d9659eef6310bdd301cde0a`，来源依据沿用现有审计。
姿态沿用当前固定基础框架派生的 ANYmal-D 路径，不宣称是 PACE 已公开数值，
也不宣称存在已核实的上游独立 ANYmal-D 官方配置。

选择理由是最小变更和来源可审计，而非训练性能。旧失败同时涉及公式 9 缺失、固定熵系数
0.01、表 8 参数未对齐、经验归一化缺失及关闭能耗项，不能据此反选动作映射。
上述主假设在 Stage1/Stage2/Stage3（阶段 1/2/3）完全一致。

禁止通过扫描尺度、裁剪阈值或姿态并比较训练表现来选择主基线。Stage1.1 的 `[-1,1]`
