- 兼容目标：官方 RSL-RL（强化学习框架）v3.0.1，提交 `2fc1f78bc1d796ffa8f07ce6b09898227db284bb`。
  选择依据是当前 PACE 公开软件的最低兼容依赖；不是论文运动训练版本确认。
- 该移植的 `paper_exact=false`；`selection_basis=official PACE artifact compatibility`（依据官方 PACE 制品兼容性）；
  `performance_based_selection=forbidden`（禁止依据性能选择）。继续使用原有 v1.0.2 PPO（近端策略优化）核心、
  策略高斯分布及优化器，不升级整个框架。
- 固定分量尺度、噪声分布/幅值、环境裁剪沿用当前配置，分类为
  `LEGGEDGYM_DERIVED_REPRODUCTION_ASSUMPTION`（基础框架派生复现假设）。论文只定义加噪对象，未公开这些数值。

## 环境输出顺序

策略：物理/无噪声观测 -> 固定尺度 -> 缩放后单位独立均匀噪声 -> 环境 ±100 裁剪 -> 策略统计更新 -> 归一化 -> 策略网络。

| 分量 | 尺度 | 缩放后噪声半幅 |
|---|---|---|
| 基座线速度 | 2 | 0.2 |
| 基座角速度 | 0.25 | 0.05 |
| 重力投影 | 1 | 0.05 |
| 命令 | (2,2,0.25) | 0 |
| 编码器关节位置 | 1 | 0.01 |
| 关节速度 | 0.05 | 0.075 |
| 上一步环境动作 | 1 | 0 |

价值：独立构造无噪声、同固定尺度的 48 维部分并做环境裁剪；拼接基座力/力矩、摩擦、接触和高程。
高程以米为单位先裁剪到 ±1，再乘 5。353 维拼接结果做环境 ±100 裁剪，再更新独立价值统计并归一化。
价值统计不使用带噪策略张量；高程等额外字段也进入价值统计。

## 归一化引擎和更新协议

```math
y=\frac{x-\mu}{\sigma+0.01}
```

采用 v3.0.1 总体方差在线合并顺序；初值为均值 0、方差 1、标准差 1、样本计数 0。
分别按环境批次更新每一维统计，策略/价值互不共享。`until=None`（不设置统计停止阈值），归一化输出不裁剪。
`forward`（前向计算）只读；只有显式 `update`（更新）且训练模式才更新。评估模式禁止更新，包括显式调用。

具体接线固定如下：

1. 首次进入训练，初始环境观测各更新一次后再进入网络；这是显式预注册的启动选择，
   与原生 v3.0.1 首批观测先用初始统计推理的行为不同，不称为逐事件完全复制上游运行器。
2. 每次环境步进返回后，用实际返回的策略/价值张量各更新一次；包括环境自动重置后的观测。
   不另取终止前观测重复更新，不因读取 getter（读取方法）重复计数。
3. 采样缓存保存环境张量；策略及价值每次网络前向均经过只读归一化，包括 PPO 小批次重算。
   优化期间不更新统计；末端价值估计也不更新。
4. 推理切换为评估模式，只使用已有统计。重复前向、动作采样和价值估计均不更新统计。
5. 恢复训练时不重置统计；新建仿真环境的首批新观测按第 1 条纳入一次。
   恢复后的同输入闭合测试在评估模式下执行，不把测试输入计入新样本。

## 完整检查点与验证

检查点必须包含策略和价值网络、原有优化器状态、迭代号、两套均值/方差/标准差/样本计数，
以及本规范标识和归一化元数据。统计作为网络子模块随模型状态保存；元数据独立保存。
不允许把旧自建 `sqrt(var+1e-8)` 检查点或缺少统计的纯网络权重当作完整 v1 恢复来源。

按顺序先做固定张量与官方模块对照，再做无仿真的合成观测 PPO 组件更新，保存检查点，
新进程加载；要求策略归一化观测、价值归一化观测、确定性动作和价值输出逐元素完全一致。
同时验证优化器状态恢复、统计在评估/小批次更新中不变、噪声顺序和价值无噪声路径。
该测试不声称恢复了模拟器/RNG（随机数生成器）状态或后续整条轨迹。

历史训练默认入口不启用兼容层；正式和验证入口继续受协议门禁保护。
通过上述实现验证后，仅关闭三个观测阻塞项；奖励项和熵斜率未决时不训练。
后续作者证据按已有动作预注册决议的启动前覆盖、启动后版本分离规则处理。

## 实现验证结果

本轮登记之后已完成实现与验证：

- [归一化引擎](../src/pace_stage1/empirical_normalization.py)使用截取的官方 v3.0.1 模块，
  保留上游声明与[许可证](../third_party/rsl_rl_normalization_v3_0_1/LICENSE)；固定上游完整模块作为离线对照。
- [运行器兼容层](../src/pace_stage1/normalization_bridge.py)在原网络前插入无可训练参数的归一化模块，
  PPO 实例类型和优化器参数对象保持不变。历史默认入口没有接入该层。
- [组件及恢复测试](../tests/test_normalization_bridge.py)采用 4 个合成张量环境、4 个采样步；
  初始批次加返回批次使策略/价值各计数 20。PPO 优化不改变统计，缓存保留环境输出。
  没有创建 Isaac Gym 模拟器，也没有测量运动表现。
- 保存后在新的 Python 进程加载，策略归一化观测、价值归一化观测、确定性动作、价值输出均逐元素完全一致；
  模型状态、优化器状态、迭代号及自适应学习率也一致。缺统计或缺规范元数据的检查点被拒绝。
- 归一化兼容层 4 项、归一化组件 5 项、PACE v2 相关 28 项、历史 Stage1 回归 30 项，共 67 项测试通过。
  正常验证运行器构造依然被训练门禁拒绝。

三个观测阻塞项已标记为 `RESOLVED_BY_PREREGISTERED_ASSUMPTION`（通过预注册假设解决）。
当前只剩 `reward.velocity_tracking_sigma`、`reward.only_positive_aggregation`、`reward.scale_by_policy_dt`
三个语义阻塞项，以及 `ppo.entropy_slope_eta` 一个可复现性阻塞项；两层训练门禁保持关闭。

下一步处理上述三个奖励语义。现有模型权重和历史训练命令没有修改；未来使用新兼容层训练时，
策略输入和优化轨迹会改变，必须按本规范记录，不能混称为历史默认路径结果。
