# PACE v2 公式（9）接线与软带宽预注册 v1

日期：2026-09-07；所属规范：`PACE_V2_SPEC_V1`。
本决议承接[动作重建预注册 v1](gpt-Stage1-PACEv2-动作重建预注册决议-v1.md)。

## 接线位置：论文精确规范

[PACE v2 第 2.3.2 节、公式（8）—（9）](https://arxiv.org/html/2509.06342v2#S2.SS3.SSS2)
明确要求先构造默认姿态加动作偏移的目标，再在发送执行器前重塑目标。
该处理不施加全局动作空间裁剪，并保留离开限位方向的控制能力。

```text
原始高斯采样
-> 已预注册的 [-100,100] 裁剪
-> ×0.5 rad（弧度）得到动作偏移
-> 加 q0 得到原始关节目标
-> Eq.(9)（公式 9），输入 q_true（真实关节位置）
-> PACEActuatorCore（执行器核心）
-> 编码器偏置进入 PD（比例微分）误差
-> 力矩/速度包络饱和
-> FIFO（先进先出）延迟队列
-> 物理仿真
```

`control.eq9_joint_limit_saturation` 的来源为 `PAPER_EXACT`（论文精确规范），
解决状态为 `RESOLVED`（已解决）。这一精确性标签针对公式及接线位置，不扩展到
原始策略输出映射、带宽数值或执行频率。

使用真实关节坐标与公式（6）的独立偏置项保持一致；编码器坐标不进入限位判断。
若以后作者明确说明采用编码器坐标，按已有作者覆盖规则处理，不静默替换。

## 软带宽：论文范围内预注册 5°

```text
control.soft_limit_band_deg
paper_range_deg = [2, 5]
chosen_value_deg = 5
chosen_value_rad = radians(5)
provenance = PAPER_RANGE（论文范围）
resolution_policy = PREREGISTERED_REPRODUCTION_CHOICE（预注册复现选择）
resolution_status = RESOLVED_BY_PREREGISTERED_PAPER_RANGE_CHOICE（通过论文范围内预注册选择解决）
paper_exact = false
```

论文描述每关节典型窄缓冲带约 2°–5°，未公开 ANYmal 的精确值。
选择上端点 5°，因为它已存在于当前重建的动作配置中，早于公式（9）的正式接入。
该值此前作为历史目标适配器参数存在，不能据此声称历史训练已经使用公式（9）。

不依据训练成功率、裁剪比例或步态表现选值；不扫描 2°/3°/5° 来选择主规范。
以后必要时单独报告带宽敏感性分析。Stage1/Stage2/Stage3（阶段 1/2/3）共用本选择，
并沿用动作决议 v1 的作者回复覆盖及版本规则。

## 独立验证路径与离散实现

新增 [PaceV2ValidationEnv（验证环境）](../src/pace_stage1/pace_v2_env.py)，
绑定 `PACE_V2_VALIDATION`（短程验证）配置身份，构造前执行既有门禁。
它使用[独立控制方法](../src/pace_stage1/pace_v2_control.py)，不调用历史
`LocomotionTargetAdapter`（目标适配器）计算目标。

历史环境只抽取目标选择和执行器步进两个可覆盖方法，默认路径的运算顺序、参数和返回值保持一致；
历史适配器和执行器核心均不修改。现有训练命令仍指向历史路径。

策略周期内原始目标保持不变；每个物理子步读取最新 `q_true`，重新计算公式（9），
随后交给执行器。当前物理子步 0.0025 秒、每策略步 4 个子步来自现有重建配置。
这个执行频率是本项目的离散实现选择，不标为论文公开的精确频率。

硬限位处目标精确取硬限位，避免浮点带宽计算留下向外目标残差。
离开当前限位方向的目标保持逐元素不变，包括越过另一侧硬限位的目标；没有全局目标裁剪。
原函数在真实位置超出硬限位时延续端点处理，这是有限仿真越界时的实现延拓。

硬限位处消失的是由目标越界引起的位置误差；存在编码器偏置、非零速度或队列中的历史力矩时，
不能声称最终力矩严格为零。测试分别检查目标语义、含偏置的 PD、执行器饱和和延迟顺序。

## 验证范围及下一步

组件测试覆盖上下侧插值、边界连续性、5° 带宽下离开限位的 30° 目标完全不变、
逐子步真实状态更新、偏置不参与公式（9）、饱和后再延迟，以及历史默认路径回归。
验证结果：PACE v2 相关 28 项测试、历史 Stage1 相关 30 项测试全部通过。
另已实际导入验证环境，确认其构造在创建模拟器前被门禁拒绝；历史默认目标方法与原计算结果逐元素一致。
本次不运行仿真训练、不修改已有模型权重。
未来使用新路径训练会改变近限位处控制行为及优化轨迹，不能与历史路径训练结果混称同一协议。
